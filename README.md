# Aetherium

Aetherium（エーテリウム）は、ローカルで動作するLLM（大規模言語モデル）とVOICEVOXを組み合わせた、**テキストと音声で会話できる**macOSアプリケーションです。

VOICEVOXの話者を自由に選べるので、**ずんだもん**や**四国めたん**など、お好みの声で会話できます。インターネット上のAIサービスには接続せず、お手元のMac上の**Ollama**と**VOICEVOXエンジン**だけで動作するため、プライバシーを守りながら利用できます。

## 主な機能

- **複数の応答言語に対応**: システム指示を日本語・英語から選択可能
- **Web検索機能**: リアルタイムのWeb検索結果を会話に活用
- **会話ログ管理**: テキスト形式やPDF形式で会話履歴を保存
- **カスタマイズ可能**: ユーザー名、発言時刻表示、読み上げ速度などを細かく調整可能
- **オフライン動作**: 自身のMac内で完結、外部サービスに依存しない

## 動作環境

- **macOS 26.0(Tahoe)以降**
- **Apple Silicon（M1以降）**
- **Ollama** を起動できること
- **VOICEVOXエンジン** はオプション（音声読み上げを使う場合のみ）

推奨: メモリ（RAM）**16GB以上**（使用するLLMモデルによって必要量が異なります）

## 事前に用意するもの

### 必須
**Ollama（ローカルLLMサーバー）** をアプリ起動前に起動しておいてください。

- デフォルト接続先: `http://127.0.0.1:11434`

### オプション
**VOICEVOXエンジン** （音声読み上げを使用する場合）も起動しておいてください。

- デフォルト接続先: `http://127.0.0.1:50021`
- VOICEVOXが起動していなくても、テキスト会話のみ可能です

接続先URLは設定画面（⌘,）で変更できます。

## Ollama（ローカルLLM）の準備
AetheriumはOllamaの OpenAI 互換 API に接続して会話を生成します。あらかじめOllamaを起動し、使いたいモデルをダウンロードしておいてください。

1. [Ollama](https://ollama.com) をインストールし、起動します。
2. 使いたいモデルをダウンロードします。例：

```bash
ollama pull llama3.2
```

3. Ollamaが起動中であれば、APIは自動的に `http://127.0.0.1:11434` で待ち受けます。
4. 起動できたら、Aetheriumの設定画面で`Model`が選べることを確認します。

```bash
# 任意（うまくいかない時の切り分け用）
curl -s http://127.0.0.1:11434/v1/models | head
```

## VOICEVOXの準備（オプション）

音声読み上げ機能を使う場合のみ、VOICEVOXエンジンを起動してください。

1. [VOICEVOX](https://voicevox.hiroshiba.jp/) をダウンロード・起動します。
2. チャット画面で音声読み上げを有効にします。
3. 設定画面（⌘,）の「音声」タブで話者と読み上げ速度を選択します。

接続できない場合の確認コマンド（オプション）:
```bash
curl -s http://127.0.0.1:50021/speakers | head
```

## 使い方

### 初回セットアップ

1. Ollamaを起動します。（VOICEVOXは音声読み上げを使う場合のみ）
2. Aetheriumを起動します。
3. 設定画面（⌘,）で以下を設定します：

**「接続」タブ:**
- **Ollama API URL**: LLMサーバーの接続先（デフォルト: http://127.0.0.1:11434/v1）
- **VOICEVOX API URL**: 音声サーバーの接続先（デフォルト: http://127.0.0.1:50021）
- **SearXNG URL**: Web検索を使う場合の検索サーバー
- **Web検索の取得件数**: 1～10件から選択

**「指示」タブ:**
- **応答言語**: AI の応答言語（日本語/英語）
- **あなたの呼び名**: チャットに表示されるユーザー名
- **AIへの指示**: AI の性格や振る舞いを設定

**「生成」タブ:**（Ollama利用時のみ）
- Temperature、Top P、Top K、Min P、Repeat Penalty、Seed など
- 出力のばらつきと品質、生成時間などを細かく調整可能

**「音声」タブ:**（VOICEVOXを使う場合）
- **話者**: VOICEVOX の話者を選択
- **Speed**: 読み上げ速度（0.5倍～2.0倍）
- チャット画面で音声読み上げの ON/OFF を切り替え

### チャット画面での操作

1. `Start Session`を押してチャット画面へ移動します。
2. 必要に応じて、入力欄の隣にある音声読み上げアイコンで ON/OFF を切り替えます。
   - オン時は AI の応答が自動的に読み上げられます
   - オフ時はテキストのみの会話になります
3. メッセージを入力して送信ボタンを押します。
4. AIが応答を生成します。音声読み上げが有効な場合は自動的に再生されます。
5. 生成中は送信ボタンが停止ボタンに変わり、いつでも生成を中断できます。

### 会話ログの保存

チャット画面のメニューから、会話全体を保存できます：
- **Markdown形式**: テキストエディタで編集可能
- **PDF形式**: 印刷・共有に適した形式

保存には、各メッセージのタイムスタンプと発言者情報が含まれます。

## インストール方法
現時点のAetheriumはアプリ署名（Developer ID署名）を行っていないため、初回起動時にmacOSのGatekeeperでブロックされることがあります。以下の手順で起動できるようになります。

### `.dmg`からインストールする場合
1. 配布された`Aetherium.dmg`をダブルクリックして開きます。
2. 表示されたウィンドウで、`Aetherium.app`を`Applications`（または`アプリケーション`）フォルダへドラッグ&ドロップします。
3. コピーが終わったら、Finderのサイドバーから`Aetherium`のディスクイメージを取り出します。
4. `アプリケーション`フォルダから`Aetherium`を起動します。

### 初回起動でブロックされた場合（未署名）
未署名のため、初回起動時に警告が出て起動できない場合があります。その場合は次の手順を試してください。

1. FinderでAetherium.appを右クリックし、`開く`を選びます（初回のみ確認ダイアログが出ます）。
2. それでもブロックされる場合は、`システム設定` → `プライバシーとセキュリティ` の下部に表示される「ブロックされました」から`このまま開く`を選びます。

### 不安な方は自分でビルドする（おすすめ）
ソースコードはGitHubで公開しています。未署名の配布物が不安な方は、ソースからご自身でビルドして起動してください。

https://github.com/motokijinde/Aetherium

## よくあるトラブル

| 問題 | 対処方法 |
|------|--------|
| **モデルが表示されない、会話が始まらない** | Ollamaが起動していることを確認してください。設定画面の「接続」タブでOllama APIのURLが正しいか確認し、Enter キーで再取得を試みてください。 |
| **読み上げが出ない** | チャット画面で音声読み上げが有効になっているか確認してください（入力欄の隣のアイコン）。VOICEVOXを使う場合は、エンジンが起動していることと、設定画面で話者が選択されていることを確認してください。 |
| **話者が表示されない** | VOICEVOXエンジンが起動しており、設定画面の「音声」タブで再取得ボタンを試してみてください。 |
| **Web検索結果が表示されない** | SearXNG サーバーが起動していることと、設定画面のURLが正しいかを確認してください。 |
| **停止したのに次の応答が返らない** | Ollama側が同時接続を制限している場合があります。数秒待った後、改善しない場合はOllamaのログを確認してください。 |
| **接続先を変更しても反映されない** | URLを変更した後、Enter キーを押して再取得してください。 |
| **ずんだもんが好きになり過ぎた** | いったん別の話者（例：四国めたん）に切り替えて落ち着いてから、再び戻すことをお勧めします。 |
