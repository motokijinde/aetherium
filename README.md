# Aetherium

Aetherium（エーテリウム）は、ローカルで動作するLLM（大規模言語モデル）とVOICEVOXを組み合わせた、**テキストと音声で会話できる**macOSアプリケーションです。

LLMは、お好みのローカルモデルを動かせる **Ollama** と、Mac内蔵の **Apple Intelligence（オンデバイス）** の2種類から選べます。どちらもインターネット上のAIサービスには接続せず、お手元のMac内で会話が完結するため、プライバシーを守りながら利用できます。VOICEVOXの話者を自由に選べるので、**ずんだもん**や**四国めたん**など、お好みの声で会話できます。

## 主な機能

- **2つのLLMプロバイダ**: Ollama（任意のローカルモデル）と Apple Intelligence（オンデバイス）を切り替えて利用可能
- **RAGドキュメント検索**: 手元のドキュメント（.md / .txt / .pdf / .xlsx）を登録し、会話中に検索して回答に活用（Ollama・Apple Intelligence の両方に対応）
- **Web検索機能**: SearXNG を介したリアルタイムのWeb検索結果を会話に活用
- **思考モード**: 思考に対応した Ollama モデルで、回答前の思考プロセスを表示
- **複数の応答言語に対応**: AI の応答言語を日本語・英語から選択可能
- **音声読み上げ**: VOICEVOX の話者で応答を読み上げ（速度調整可）
- **応答の再生成**: 同じ質問に対する別の応答を生成し、切り替えて比較
- **会話ログ管理**: Markdown形式・PDF形式で会話履歴を保存
- **カスタマイズ可能**: ユーザー名、AIへの指示、生成パラメータ（Ollama）などを細かく調整可能
- **オフライン動作**: LLM はお手元のMac内で完結し、外部のAIサービスに依存しない

## 動作環境

- **macOS 26.0(Tahoe)以降**
- **Apple Silicon（M1以降）**
- LLM として、次のいずれかが利用できること
  - **Ollama** を起動できる、または
  - **Apple Intelligence** が有効になっている（システム設定で有効化）
- **VOICEVOXエンジン**（音声読み上げを使う場合のみ・オプション）
- **SearXNG**（Web検索を使う場合のみ・オプション）
- **RAG API サーバー**（ドキュメント検索を使う場合のみ・オプション）

推奨: メモリ（RAM）**16GB以上**（使用するLLMモデルによって必要量が異なります）

## 事前に用意するもの

### LLM（いずれか必須）

会話には LLM が必要です。以下のどちらか一方が利用できれば動作します。

- **Ollama**: 任意のローカルモデルを使いたい場合（後述の手順で起動・モデル取得）
- **Apple Intelligence**: 追加のサーバー起動が不要なオンデバイスAIを使いたい場合（システム設定 → Apple Intelligence & Siri で有効化）

### オプション

- **VOICEVOXエンジン**: 応答の音声読み上げを使う場合（デフォルト接続先: `http://127.0.0.1:50021`）
- **SearXNG**: Web検索を使う場合（デフォルト接続先: `http://localhost:8080`）
- **RAG API サーバー**: ドキュメント検索を使う場合（デフォルト接続先: `http://127.0.0.1:8000`）。セットアップは [motokijinde/rag-server](https://github.com/motokijinde/rag-server) を参照してください。

接続先URLは設定画面（⌘,）の「接続」タブで変更できます。

## Ollama（ローカルLLM）の準備

AetheriumはOllamaの OpenAI 互換 API に接続して会話を生成します。あらかじめOllamaを起動し、使いたいモデルをダウンロードしておいてください。

1. [Ollama](https://ollama.com) をインストールし、起動します。
2. 使いたいモデルをダウンロードします。例：

```bash
ollama pull llama3.2
```

3. Ollamaが起動中であれば、APIは自動的に `http://127.0.0.1:11434` で待ち受けます。
4. 起動できたら、Aetheriumの起動画面で `Model` が選べることを確認します。

```bash
# 任意（うまくいかない時の切り分け用）
curl -s http://127.0.0.1:11434/v1/models | head
```

## Apple Intelligence（オンデバイスLLM）の準備

Ollamaを使わず、Mac内蔵のオンデバイスAIで会話することもできます。

1. `システム設定` → `Apple Intelligence & Siri` から Apple Intelligence を有効にします。
2. Aetheriumの起動画面でプロバイダを `Apple Intelligence` に切り替えます。
3. 「オンデバイス AI が利用可能です」と表示されれば準備完了です。

Apple Intelligence では追加のサーバー起動やモデルのダウンロードは不要です。なお、オンデバイスモデルはOllamaの大きなモデルに比べてツール呼び出し（Web検索・RAG検索）の精度が劣る場合があります。

## VOICEVOXの準備（オプション）

音声読み上げ機能を使う場合のみ、VOICEVOXエンジンを起動してください。

1. [VOICEVOX](https://voicevox.hiroshiba.jp/) をダウンロード・起動します。
2. チャット画面で音声読み上げを有効にします。
3. 設定画面（⌘,）の「音声」タブで話者と読み上げ速度を選択します。

接続できない場合の確認コマンド（オプション）:
```bash
curl -s http://127.0.0.1:50021/speakers | head
```

## RAGドキュメント検索の準備（オプション）

登録したドキュメントから関連情報を検索し、会話の回答に活用する機能です。利用には、**RAG API サーバー**を別途起動しておく必要があります。

1. RAG API サーバーをセットアップ・起動します。手順は別リポジトリ [motokijinde/rag-server](https://github.com/motokijinde/rag-server) を参照してください（デフォルト接続先: `http://127.0.0.1:8000`）。
2. 設定画面（⌘,）の「接続」タブで `RAG API URL` と `RAG検索の取得件数` を確認・調整します。
3. ドキュメントの登録方法は後述の「RAGドキュメントの登録」を参照してください。

> RAG API サーバーはこのアプリとは別のコンポーネントです。セットアップや接続できないときの確認方法は [motokijinde/rag-server](https://github.com/motokijinde/rag-server) を参照してください。

## 使い方

### 初回セットアップ

1. 使いたいLLMを準備します（Ollamaを起動する／Apple Intelligence を有効にする）。音声読み上げを使う場合はVOICEVOXも起動します。
2. Aetheriumを起動します。
3. 起動画面でプロバイダを選択します。
   - **Ollama**: 続いて使用するモデルを選びます。
   - **Apple Intelligence**: 「オンデバイス AI が利用可能です」と表示されることを確認します。
4. 必要に応じて設定画面（⌘,）で各種設定を行います。

**「接続」タブ:**
- **Ollama API URL**: LLMサーバーの接続先（デフォルト: http://127.0.0.1:11434/v1）
- **VOICEVOX API URL**: 音声サーバーの接続先（デフォルト: http://127.0.0.1:50021）
- **SearXNG URL**: Web検索を使う場合の検索サーバー
- **Web検索の取得件数**: 1～10件から選択
- **RAG API URL**: ドキュメント検索サーバーの接続先（デフォルト: http://127.0.0.1:8000）
- **RAG検索の取得件数**: 1～10件から選択

**「指示」タブ:**
- **応答言語**: AI の応答言語（日本語/英語）
- **あなたの呼び名**: チャットに表示されるユーザー名
- **AIへの指示**: AI の性格や振る舞いを設定

**「生成」タブ:**（Ollama利用時のみ）
- Context Size、Temperature、Top P、Top K、Min P、Repeat Penalty、Seed、Num Predict など
- 出力のばらつきと品質、生成時間、リソースの使い方などを細かく調整可能

**「音声」タブ:**（VOICEVOXを使う場合）
- **話者**: VOICEVOX の話者を選択
- **Speed**: 読み上げ速度（0.5倍～2.0倍）
- チャット画面で音声読み上げの ON/OFF を切り替え

### チャット画面での操作

1. `Start Session`を押してチャット画面へ移動します。
2. 入力欄の下にあるトグルで、必要な機能を切り替えます（コンテキストが空のときに切替可）。
   - 🌐 **Web検索**: SearXNG を使ったWeb検索（Ollama・Apple Intelligence 両対応）
   - 📚 **RAG検索**: 登録ドキュメントの検索（Ollama・Apple Intelligence 両対応）
   - 💡 **思考モード**: 思考対応の Ollama モデルで利用可
3. 音声読み上げアイコンで読み上げの ON/OFF を切り替えます。
   - オン時は AI の応答が自動的に読み上げられます
   - オフ時はテキストのみの会話になります
4. メッセージを入力して送信ボタンを押します。
5. AIが応答を生成します。音声読み上げが有効な場合は自動的に再生されます。
6. 生成中は送信ボタンが停止ボタンに変わり、いつでも生成を中断できます。
7. 応答の再生成ボタンで、同じ質問に対する別の応答を生成して切り替えられます。

### RAGドキュメントの登録

ツールバーの 📚（ドキュメント / 最終同期インジケータ）をクリックすると、RAGドキュメント管理画面が開きます。RAG検索のON/OFFに関わらず、いつでも開いて登録できます。

1. **監視フォルダを追加**: 「Watched Folders」の＋ボタンから、ドキュメントの入ったフォルダを選びます。
2. 次のファイルが対象になります。
   - `.md` / `.txt` / `.pdf` の単体ファイル
   - `名前.xlsx` と同名フォルダ `名前/` 内の `名前_【タブ名】.md`（各タブが1ドキュメントとして扱われます）
3. **今すぐ同期**ボタンで、新規・更新・削除されたドキュメントをサーバーへ反映します。
   - 画面を開いたままフォルダにファイルを追加した場合も、同期時に自動で再スキャンされます。
4. 同期が終わると、各ファイルの状態（同期済み／更新あり／新規など）が一覧で確認できます。

> 登録だけしておけば、RAG検索をオフにしていてもドキュメントはサーバーに保持されます。検索で使うときにトグルをオンにしてください。

### 会話ログの保存

チャット画面のメニューから、会話全体を保存できます：
- **Markdown形式**: テキストエディタで編集可能
- **PDF形式**: 印刷・共有に適した形式

保存には、各メッセージのタイムスタンプと発言者情報が含まれます。

## インストール方法
現時点のAetheriumはアプリ署名（Developer ID署名）を行っていないため、初回起動時にmacOSのGatekeeperでブロックされることがあります。以下の手順で起動できるようになります。

### `.dmg`からインストールする場合
1. 配布された`Aetherium.dmg`をダブルクリックして開きます。
2. 表示されたウィンドウで、`Aetherium.app`を`Applications`（または`アプリケーション`）フォルダへドラッグ&ドロップします。
3. コピーが終わったら、Finderのサイドバーから`Aetherium`のディスクイメージを取り出します。
4. `アプリケーション`フォルダから`Aetherium`を起動します。

### 初回起動でブロックされた場合（未署名）
未署名のため、初回起動時に警告が出て起動できない場合があります。その場合は次の手順を試してください。

1. FinderでAetherium.appを右クリックし、`開く`を選びます（初回のみ確認ダイアログが出ます）。
2. それでもブロックされる場合は、`システム設定` → `プライバシーとセキュリティ` の下部に表示される「ブロックされました」から`このまま開く`を選びます。

### 不安な方は自分でビルドする（おすすめ）
ソースコードはGitHubで公開しています。未署名の配布物が不安な方は、ソースからご自身でビルドして起動してください。

https://github.com/motokijinde/Aetherium

## よくあるトラブル

| 問題 | 対処方法 |
|------|--------|
| **モデルが表示されない、会話が始まらない** | Ollamaが起動していることを確認してください。設定画面の「接続」タブでOllama APIのURLが正しいか確認し、Enter キーで再取得を試みてください。 |
| **Apple Intelligence が使えない** | 「Apple Intelligence が有効になっていません」と表示される場合は、システム設定 → Apple Intelligence & Siri から有効にしてください。Apple Silicon 以外のMacには対応していません。 |
| **読み上げが出ない** | チャット画面で音声読み上げが有効になっているか確認してください（入力欄の隣のアイコン）。VOICEVOXを使う場合は、エンジンが起動していることと、設定画面で話者が選択されていることを確認してください。 |
| **話者が表示されない** | VOICEVOXエンジンが起動しており、設定画面の「音声」タブで再取得ボタンを試してみてください。 |
| **Web検索結果が表示されない** | SearXNG サーバーが起動していることと、設定画面のURLが正しいかを確認してください。 |
| **RAG検索／登録ができない** | RAG API サーバーが起動していることと、設定画面の「接続」タブのRAG API URLが正しいかを確認してください。ドキュメント管理画面の接続ステータスでも確認できます。サーバーのセットアップは [motokijinde/rag-server](https://github.com/motokijinde/rag-server) を参照してください。 |
| **Web検索・RAGのトグルが押せない** | 会話中（コンテキストに履歴があるとき）は変更できません。コンテキストをクリアすると切り替えられます。 |
| **停止したのに次の応答が返らない** | Ollama側が同時接続を制限している場合があります。数秒待った後、改善しない場合はOllamaのログを確認してください。 |
| **接続先を変更しても反映されない** | URLを変更した後、Enter キーを押して再取得してください。 |
| **ずんだもんが好きになり過ぎた** | いったん別の話者（例：四国めたん）に切り替えて落ち着いてから、再び戻すことをお勧めします。 |
